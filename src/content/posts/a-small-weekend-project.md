周末开始时，我只想给书桌旁边加一盏不太亮的灯。它不需要连接网络，也不需要手机控制，只要在晚上打开时，能够让桌面保持一块温和的光。

真正动手之后，事情很快变得比想象中复杂：灯放在哪里、线要怎么收、开关是否顺手、亮度会不会影响屏幕阅读，都需要做出选择。

## 先把目标缩小

我给这个项目写下了四条边界：

- 一个晚上可以完成基本组装。
- 不增加新的应用或账号。
- 任何一个部件都可以独立替换。
- 打开和关闭都不需要寻找手机。

边界让很多“也许可以加入”的想法自动退出了项目。没有边界时，兴趣会不断把项目推向更大的方向，最后连最初想解决的问题都看不见了。

## 记录过程，而不是只记录结果

我用一张纸画了三种摆放方式：

```text title="桌面布局草图"
窗户
┌──────────────────────────┐
│        显示器             │
│                          │
│  灯 A          笔记本     │
│                          │
│  书架          灯 B       │
└──────────────────────────┘
书桌前沿
```

灯 A 的光线更均匀，但会占用书架旁的空间；灯 B 更容易操作，却会在屏幕上留下反光。最后我选择了灯 A，并把开关放到桌面边缘。

> [!NOTE]
> 草图的价值不是画得准确，而是让不同选择可以被放在一起比较。

## 哪些地方没有按计划进行

第一次组装时，线材比预计更长。为了让它不出现在视线里，我尝试把线藏到桌板下面，结果每次移动桌子都需要重新整理。后来我接受了一个更简单的方案：只固定最容易松动的部分，剩下的线留出可以移动的余量。

这件事提醒我，整洁不应该以牺牲可维护性为代价。看起来完全没有线，未必比能轻松调整的线更好。

## 完成后的检查

- [x] 灯光不会直接照射眼睛
- [x] 坐在桌前时开关容易触碰
- [x] 桌面仍然保留写字和放书的空间
- [x] 移动设备后不需要重新布置所有线材
- [ ] 给灯罩加一个更容易清洁的表面

> [!TIP]
> 小项目不必一次做到最终形态。只要第一版足够安全、足够好用，就已经为下一次改进提供了真实的使用反馈。

现在晚上坐到桌前时，我不再需要先调整环境。灯只是安静地亮在那里，提醒我可以开始读几页书，或者继续写完一段还没有结束的文字。
